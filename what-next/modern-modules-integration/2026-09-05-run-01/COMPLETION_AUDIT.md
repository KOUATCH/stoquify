## Engineering boundaries that are not user signatures

Reconciliation can receive a late provider statement for an earlier payment. A date-only stop exception would be unsafe, and admitting only inputs already stored before stopping would strand that late evidence. A durable retained-source scope and supplementary reconciliation lifecycle are still needed before offering this stop policy. Accounting stopping remains unavailable because reconciliation is a required dependent. This limitation does not prevent configuring and preparing those existing workspaces.

Commercial grant issuance, prices, provider credentials, real accounting setup approval, country-expert evidence and customer rollout authority remain external/domain inputs. They must not be fabricated by the builder. A missing input is displayed with its existing domain route; production provider submission remains outside the supported sandbox compliance scope.
