## Scope decision

No edit to `jest.config.ts` or `tsconfig.json` is justified by the completed probes. In particular, no source/test exclusions were added, no type errors were suppressed, and the ordinary runner's Next integration was retained. The historical Jest startup timeout is not currently reproduced. The full compiler needs an execution budget exceeding the observed eight-minute cold run on this shared host; any future performance changes need profiling against the semantic workload, rather than silently removing source coverage.
