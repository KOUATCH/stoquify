# Module Graduation Gates

| Gate | Minimum evidence |
|---|---|
| Security | Tenant isolation, RBAC, entitlement, step-up, maker-checker, and redaction tests |
| Registry | All critical and output surfaces explicitly owned and classified |
| Decision | Canonical access result before data access with stable reason codes |
| Lifecycle | Active, read-only, suspended, expired, dependency-gap, and reactivation behavior |
| Leakage | Reports, exports, jobs, webhooks, proofs, BI, caches, and public tokens tested |
| UX | Direct-route parity, robust states, accessibility, mobile and desktop checks |
| Operations | Metrics, alerts, failure budget, support runbook, incident owner |
| Rollback | Kill switch and recovery smoke within the declared objective |
| Evidence | Current immutable artifacts tied to policy and application versions |

Certification states are `candidate`, `observing`, `certified`, `rejected`, `expired`, or `revoked`.
