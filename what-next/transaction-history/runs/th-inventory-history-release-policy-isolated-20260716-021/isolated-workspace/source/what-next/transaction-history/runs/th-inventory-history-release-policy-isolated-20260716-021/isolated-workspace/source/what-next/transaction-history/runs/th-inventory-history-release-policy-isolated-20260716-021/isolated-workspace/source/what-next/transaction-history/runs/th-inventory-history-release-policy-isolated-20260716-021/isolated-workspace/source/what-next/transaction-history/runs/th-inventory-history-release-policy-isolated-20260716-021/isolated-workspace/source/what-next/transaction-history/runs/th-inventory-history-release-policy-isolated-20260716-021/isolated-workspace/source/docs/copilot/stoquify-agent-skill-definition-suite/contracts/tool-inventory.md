# Verified Tool and Service Inventory

The source suite names service domains, not invented function calls. Exact command allowlists must be resolved during implementation. Verified domains: `accounting`, `analytics`, `assurance`, `auth`, `bi`, `cash-command`, `compliance`, `controls`, `daily-habit`, `events`, `evidence`, `finance`, `history`, `hris`, `inventory`, `location`, `manager-action-center`, `modules`, `organization`, `owner-war-room`, `payments`, `payroll`, `pos`, `purchase-order`, `purchasing`, `reconciliation`, `regulatory`, `roles`, `security`, `signals`, `snapshots`, `stock-to-cash`, `supplier`, and `users`.

No definition may convert a domain mapping into write authority.
