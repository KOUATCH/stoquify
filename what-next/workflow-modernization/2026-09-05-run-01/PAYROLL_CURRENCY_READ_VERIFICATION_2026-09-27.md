## Correction and evidence

The source now groups each query by its recorded currency. A total is numeric only when every group uses the organization's currency; a successful empty query returns zero. A different currency produces `null`, its original amount/count breakdown and an explicit conversion-evidence limitation. No exchange rate or accounting conversion is invented. Failed queries reject. Missing organizations reject rather than supplying a default currency. Source fingerprints include the currency and breakdowns, including when both old and new combined totals are null.

Active cases still produce their warning and authorized recovery action. Cash Command preserves null in its summary/card/risk and selects recovery by case count. Numeric severity comparisons require a numeric total. Existing records and financial controls remain unchanged. EN/FR Digest limitations state currencies and unavailable totals; unknown/custom evidence text remains intact. Restricted payroll readers receive a restricted-source limitation without payroll amounts.
