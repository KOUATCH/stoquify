# Use and support the Daily Digest

Open `/en/dashboard/daily-digest` or `/fr/dashboard/daily-digest` after signing in. Available workspaces depend on current role, permissions and module access. A role name alone does not grant organization-wide authority.

Choose a workspace, then Brief for figures, Command for available next actions, or Investigate for source details. Check the period, currency, freshness and source limitations before relying on a figure. Weekly uses its own seven-day UTC window; current balances are not seven-day movements. A blank/unavailable amount is not zero. Different currencies are disclosed separately and are not converted or added together.

Expand source limitations to understand missing evidence. Selecting a workspace or reading a status does not approve, post, pay or activate anything. Use the source link for the permitted business operation. Back returns to the selected Digest view. A previously visible link can become denied when authority changes.

If no workspace or action is available, ask the organization administrator to review the actual role permissions, module grant status/validity and location assignments. Supply the route, selected workspace, timestamp and displayed denial reason. The administrator obtains the required information from organization access/module settings and the authoritative assignment records; do not invent a grant or change source evidence to hide the limitation.

On a query error, retry. If it persists, retain the visible error/reference and timestamp for the application operator. A failed read must remain an error, not an empty success. After session expiry, sign in through the localized form; the selected workspace/mode is restored. Review the refreshed limitations again.

For currency or payroll warnings, the authorized finance/payroll owner reviews the original batches, declarations, balance cases and independent posting/payment evidence. Changing currency alone cannot establish missing proof. For stale evidence, refresh and investigate the owning source if it remains stale. Digest has no separate draft, approval, cancellation, export or reversal process.

Keyboard users can move through the workspace selector and activate modes/actions with standard controls. The selector scrolls horizontally on narrow screens; the content reflows. EN/FR doubled-text and browser keyboard checks are recorded, with native screen-reader speech/browser zoom still unverified.

Operators: use the [final evidence record](DAILY_DIGEST_FINAL_VERIFICATION_2026-09-27.md) for read invariants, safe isolated failure injection and the additive disposable schema repair. Test scripts create synthetic fixtures and must not be pointed at live customer databases. Existing release gates and rollout approvals remain effective.
