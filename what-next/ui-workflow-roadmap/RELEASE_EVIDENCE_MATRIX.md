## Shared browser and acceptance record

For each case capture: acceptance ID (`UCxx-scenario`), runtime/source revision, non-secret environment, role/grants, synthetic fixture IDs, EN/FR, actual CSS viewport dimensions, keyboard and focus sequence, expected/observed outcome, sanitized screenshot or response evidence, elapsed task time and named reviewer. A requested 390px override is not evidence of an actual 390px viewport. Never put session tokens, raw proof, recipients or private payloads into artifacts.

Run allowed, denied, limited-location, module-disabled, expired-session and actor/tenant-switch tasks where applicable. Check loading, empty, unavailable, stale and uncertain outcomes. For commands, include commit-with-lost-response and concurrent actions. A disabled panel or empty fixture proves presentation only. Accessibility needs actual assistive-technology verification in addition to DOM assertions.
