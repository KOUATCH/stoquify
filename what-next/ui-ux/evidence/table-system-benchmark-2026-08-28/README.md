# Table System Benchmark Evidence

Date: 2026-08-28

This directory is the reproducibility bundle for the Stoquify enterprise table benchmark and harmonization roadmap.

Files:

- `source-manifest.json`: external primary sources and local repository evidence, with access dates, supported claims, and limitations.
- `scorecard.json`: 100-point weighting, 0-5 raw scores, formula, totals, and confidence.
- `route-inventory.json`: representative table-bearing surfaces across Stoquify module families.
- `reviewer-lens-register.json`: disposition of every multidisciplinary review lens.
- `screenshot-manifest.json`: screenshot boundary and capture status.

Evidence rules:

- External capability claims require a source ID.
- Repository observations identify a local source or prior inventory.
- Scores are assessments, not certifications.
- URLs were accessed on 2026-08-28.
- No authenticated competitor or Stoquify table screenshot was captured because no approved tenant/session and seeded data were available for reproducible review.
