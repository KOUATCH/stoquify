# Referral-Worthy Platform Features Prompt

```text
Act as a senior product strategist and SaaS growth advisor.

We are building a business operations platform for SMBs, with core workflows around accounting, inventory, POS, payroll, compliance, reporting, and business control. We are already planning to add an in-system AI copilot, and possibly WhatsApp automation.

Beyond those two ideas, identify the most valuable product features we should consider adding to significantly increase user value, retention, daily usage, and word-of-mouth referrals.

The goal is not just to add features, but to create sticky experiences that make users feel the platform is indispensable, delightful, and worth urgently recommending to other business owners, accountants, managers, and operators.

Please structure your answer as follows:

1. High-impact feature ideas
   - List features that would materially improve the product offering.
   - Focus on features that solve painful, frequent, expensive, or emotionally frustrating problems.

2. Stickiness and habit loops
   - Explain which features would make users return daily or weekly.
   - Identify workflows that could become part of the user's operating rhythm.

3. Viral/referral triggers
   - Suggest features that naturally make users invite coworkers, accountants, suppliers, customers, or peer businesses.
   - Explain why each feature could create excitement or word-of-mouth.

4. Differentiation
   - Identify features that would make the platform feel meaningfully different from ordinary accounting, POS, ERP, or inventory tools.

5. Prioritization
   - Rank the ideas by impact, implementation complexity, revenue potential, and referral potential.
   - Recommend the top 5 features to build first.

6. Product packaging
   - Suggest which features should be free, paid, premium, or enterprise-only.
   - Explain how these features could improve pricing power and customer loyalty.

Be practical and specific. Avoid generic SaaS advice. Think in terms of real SMB pain, African/OHADA market realities, operational trust, compliance, cash flow, inventory leakage, payroll accuracy, fraud prevention, business intelligence, and accountant collaboration.
```

## Short Version

```text
Beyond our planned AI copilot and possible WhatsApp automation, what high-impact features should we build to make this SMB operations platform indispensable, habit-forming, highly differentiated, and naturally referral-worthy?
```
