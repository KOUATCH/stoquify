# Stoquify S explorations — REJECTED

User rejected this exploration on 14 September 2026. None of these alternatives is selected. Retained for design history only; the original solid S remains the current proposal.

Open index.html. Three proposed alternatives: Folded ribbon, Twin track, Precision cut. The original S is included for comparison.

Previous recommendation (rejected): Twin track for larger uses, paired with the original solid S below 32 px. Precision cut is the simpler versatile alternative.

Each option has color, monochrome, reversed, and full-logo SVG/PNG files. SVGs contain actual vector geometry; Twin track and Precision cut use vector masks. Some sign cutters require masks flattened into boolean paths before manufacture. Mint fold accents are decorative, not functional UI boundaries.

The original branding kit and archive have not been replaced.
