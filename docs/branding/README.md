# Stoquify brand kit

**Start with `index.html`.** Open it in a browser to compare the three directions and switch the website preview between light/dark and English/French. Keep the folder intact so images and bundled fonts resolve.

Recommended direction: **A — Steady flow**, the teal S monogram.

- `concept-comparison.png`: all three concepts at a glance.
- `identity-overview.png`: recommended logo variants and app treatments.
- `brand-guidelines.md`: usage rules, typography, positioning, evidence and adoption plan.
- `logos/`: outlined SVG masters, transparent PNGs, app/social icons and favicons.
- `applications/`: website and dashboard examples, fictional document/card layouts, sign and social artwork, and an AI-generated office visualization.
- `icons/`: six original SVG/PNG interface symbols.
- `fonts/`: original Manrope and Inter variable fonts with their licenses.
- `brand-tokens.css` and `palette.json`: proposed theme definitions.
- `asset-manifest.json`: file inventory, dimensions, SHA-256 hashes and limitations.
- `verification/`: measured contrast, glyph checks, export checks, browser checks and contact sheets.

All work is a design proposal. Production application files remain unchanged. Print assets require real contact details, bleed, color conversion and printer proofs. The generated photograph is a material visualization; the vector masters are authoritative.

## Rejected exploration history

`s-explorations/` contains the later unusual-S alternatives. The user rejected that exploration; it is retained only as design history. Its HTML page, README and status.json identify the rejection. The original solid S remains the current proposal.
