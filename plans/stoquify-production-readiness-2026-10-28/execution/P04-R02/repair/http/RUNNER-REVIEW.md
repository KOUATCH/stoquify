# Isolated repaired routing gate

The launcher preserves only OS variables, compiles a new synthetic fixture, and contacts loopback only. It copies ten hash-bound sources; authz/errors are explicit fixtures. The Next configuration is AST-extracted actual images and rewrites policy, with one-worker local build settings. No root app setup, environment files, database, original assets, production flags or network services are admitted. Development tests public-source compatibility; production compiles the minimal fixture and reads only private storage. Both seed a private optimizer cache entry through installed Next cache APIs, check both URL families and public controls, then close the owned listener/process. Artifacts and failed attempts are preserved. This is not a full application build or actual session lifecycle qualification.
